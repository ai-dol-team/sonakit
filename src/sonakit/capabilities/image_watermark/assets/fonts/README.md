# Bundled watermark fonts

These font files are bundled so watermark rendering does not depend on fonts installed on the host.

## Sources

The Latin, Cyrillic, Devanagari, Telugu, and Tamil fonts come from
[`notofonts/noto-fonts`](https://github.com/notofonts/noto-fonts) at commit
`ffebf8c1ee449e544955a7e813c54f9b73848eac`.

The Simplified Chinese and Japanese fonts come from
[`notofonts/noto-cjk`](https://github.com/notofonts/noto-cjk) at commit
`f8d157532fbfaeda587e826d4cd5b21a49186f7c`.
